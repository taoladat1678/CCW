       * Cấu hình phân trang: PageRequest.of(page, size, Sort.by(Sort.Direction.DESC, "id"))
       * Mặc định: size = 4 sản phẩm / 1 trang
       * Trả về: Page<ProductResponse>
     + public List<ProductResponse> getAllProducts() : Lấy toàn bộ sản phẩm không phân trang

4. Tầng REST API Controller (Trả dữ liệu JSON phân trang cho Admin):
   - File: ShopGiayTheThao/src/main/java/com/example/ShopGiayTheThao/controller/AdminApiController.java
   - Hàm:
     + public ResponseEntity<Page<ProductResponse>> getAdminProducts(@RequestParam(name = "page", defaultValue = "0") int page, @RequestParam(name = "size", defaultValue = "4") int size)
     + URL API: GET /api/admin/products?page=0&size=4
     + Mục đích: Trả về JSON đối tượng Page chứa content (4 sản phẩm), totalPages, totalElements, số trang hiện tại...

5. Tầng Spring MVC Controller (Render giao diện product.html có phân trang):
   - File: ShopGiayTheThao/src/main/java/com/example/ShopGiayTheThao/controller/AdminController.java
   - Hàm: public String products(@RequestParam(name = "page", defaultValue = "0") int page, @RequestParam(name = "size", defaultValue = "4") int size, Model model)
     + Code truyền dữ liệu: 
       * Page<ProductResponse> productPage = productService.getProductsForAdmin(page, size);
       * model.addAttribute("productPage", productPage);
       * model.addAttribute("products", productPage.getContent());
       * model.addAttribute("currentPage", productPage.getNumber());
       * model.addAttribute("totalPages", productPage.getTotalPages());
       * model.addAttribute("totalElements", productPage.getTotalElements());
       * model.addAttribute("pageSize", size); // Mặc định là 4
       * model.addAttribute("categories", productService.getAllCategories());

   - File: ShopGiayTheThao/src/main/resources/templates/admin/product.html

       * Dropdown lọc Danh mục: thẻ <select id="filter-category"> duyệt th:each="c : ${categories}"
       * Dropdown lọc Thương hiệu: thẻ <select id="filter-brand"> duyệt th:each="b : ${brands}"
     + Bảng hiển thị sản phẩm (Table body):
       * Dòng rỗng thông báo: <tr th:if="${products == null or #lists.isEmpty(products)}">
       * Lặp 4 sản phẩm của trang: <tr th:each="product : ${products}" th:data-id="${product.id}" th:data-desc="${product.description}">
       * Cột Checkbox: value="${product.id}"
       * Cột Hình ảnh: img src "${product.thumbnail}"
       * Cột Tên sản phẩm: "${product.name}", mã SP-${product.id} và số lượng size
       * Cột Thương hiệu: "${product.brandName}"
       * Cột Danh mục: "${product.categoryName}"
       * Cột Giá bán: Giá sale "${product.salePrice}" / Giá gốc "${product.price}" định dạng VNĐ
       * Cột Kho hàng: "${product.totalStock} đôi"
       * Cột Trạng thái: "Còn hàng" / "Sắp hết hàng" / "Hết hàng" dựa theo status và totalStock

       * Dòng thông tin: Trang [[${currentPage + 1}]] / [[${totalPages}]] (Tổng [[${totalElements}]] sản phẩm)
       * Nút "← Trước": <a th:if="${currentPage > 0}" th:href="@{/admin/products(page=${currentPage - 1}, size=${pageSize})}" class="page-chip">← Trước</a>
       * Danh sách số trang: duyệt th:each="pageNum : ${#numbers.sequence(0, totalPages - 1)}"
         - Trang hiện tại: thẻ <span class="page-chip active">
         - Các trang khác: thẻ <a class="page-chip" th:href="@{/admin/products(page=${pageNum}, size=${pageSize})}">
       * Nút "Sau →": <a th:if="${currentPage < totalPages - 1}" th:href="@{/admin/products(page=${currentPage + 1}, size=${pageSize})}" class="page-chip">Sau →</a>

            "WHERE (:keyword IS NULL OR LOWER(p.name) LIKE LOWER(CONCAT('%', :keyword, '%')) OR CAST(p.id AS string) LIKE CONCAT('%', :cleanKeyword, '%')) " +
            "AND (:categoryId IS NULL OR p.category.id = :categoryId) " +

            "     :statusFilter IS NULL OR :statusFilter = '' " +

            "     OR (:statusFilter = '0' AND (p.status = 0 OR (SELECT COALESCE(SUM(ps2.stock), 0) FROM ProductSize ps2 WHERE ps2.product = p) = 0)) " +

8. XỬ LÝ XÓA HOÀN TOÀN BRAND VÀ CATEGORY KHỎI DB - TỰ ĐỘNG CHUYỂN SẢN PHẨM SANG BRAND / CATEGORY NGẪU NHIÊN TRÁNH LỖI BAD REQUEST
====================================================================================================
- Mục đích: Khi thực hiện thao tác Xóa Thương Hiệu (Brand) hoặc Danh Mục (Category) tại trang Admin (brand.html & cate.html):
  + Xóa vĩnh viễn (hard-delete) bản ghi thương hiệu / danh mục đó khỏi cơ sở dữ liệu (Database).
  + Tự động tìm tất cả sản phẩm đang liên kết với thương hiệu / danh mục bị xóa và chuyển hướng ngẫu nhiên sang một thương hiệu / danh mục khác còn tồn tại trong hệ thống.
  + Nếu không còn thương hiệu / danh mục nào khác trong DB, tự động khởi tạo bản ghi mặc định hệ thống ("Khác") để tiếp nhận sản phẩm, tuyệt đối không bị lỗi Bad Request hoặc vi phạm ràng buộc khóa ngoại (Foreign Key constraint).
- Vị trí các file và hàm đã xử lý:
  1. File: ShopGiayTheThao/src/main/java/com/example/ShopGiayTheThao/repository/ProductRepository.java
     + Thêm phương thức truy vấn:
       * List<Product> findAllByBrandId(Long brandId);
       * List<Product> findAllByCategoryId(Long categoryId);
  2. File: ShopGiayTheThao/src/main/java/com/example/ShopGiayTheThao/service/BrandServiceImpl.java
     + Tiêm phụ thuộc (Dependency Injection): ProductRepository productRepository.
     + Hàm xử lý: public void deleteBrand(Long id)
       - Tìm tất cả sản phẩm thuộc thương hiệu bị xóa bằng productRepository.findAllByBrandId(id).
       - Nếu có sản phẩm: lọc danh sách thương hiệu còn lại khác id hiện tại, chọn ngẫu nhiên một thương hiệu đích (targetBrand = otherBrands.get(ThreadLocalRandom.current().nextInt(...))) hoặc tạo mới nếu chưa có.
       - Cập nhật lại brand cho tất cả sản phẩm và lưu bằng productRepository.saveAll(products); productRepository.flush().
       - Xóa rỗng danh sách liên kết bộ nhớ brand.getProducts().clear().
       - Xóa hoàn toàn thương hiệu khỏi cơ sở dữ liệu: brandRepository.delete(brand); brandRepository.flush().
  3. File: ShopGiayTheThao/src/main/java/com/example/ShopGiayTheThao/service/CategoryService.java
     + Tiêm phụ thuộc (Dependency Injection): ProductRepository productRepository.
     + Hàm xử lý: public void deleteCategory(Long id)
       - Tìm tất cả sản phẩm thuộc danh mục bị xóa bằng productRepository.findAllByCategoryId(id).
       - Nếu có sản phẩm: lọc danh sách danh mục còn lại khác id hiện tại, chọn ngẫu nhiên một danh mục đích (targetCategory = otherCategories.get(ThreadLocalRandom.current().nextInt(...))) hoặc tạo mới nếu chưa có.
       - Cập nhật lại category cho tất cả sản phẩm và lưu bằng productRepository.saveAll(products); productRepository.flush().
       - Xóa rỗng danh sách liên kết bộ nhớ category.getProducts().clear().
       - Xóa hoàn toàn danh mục khỏi cơ sở dữ liệu: categoryRepository.delete(category); categoryRepository.flush().
