================================================================================
                    TẦNG REPOSITORY (DATA ACCESS LAYER) LÀ GÌ? ĐỂ LÀM GÌ?
================================================================================

1. ĐỊNH NGHĨA:
- Repository (hay Data Access Object - DAO) là tầng chịu trách nhiệm tương tác trực tiếp với Cơ sở dữ liệu (Database).
- Trong Spring Boot / Spring Data JPA, Repository thường là một `interface` kế thừa từ `JpaRepository<Entity, ID>` hoặc `CrudRepository<Entity, ID>`.
- Được đánh dấu bằng annotation `@Repository` (khi kế thừa `JpaRepository` thì Spring tự nhận diện).

2. REPOSITORY ĐỂ LÀM GÌ? (MỤC ĐÍCH & VAI TRÒ):
- Thực hiện các thao tác CRUD cơ bản mà không cần viết câu lệnh SQL thủ công:
  + Create: `save(entity)` (Thêm mới)
  + Read: `findById(id)`, `findAll()`, `existsById(id)`, `count()` (Đọc/tìm kiếm)
  + Update: `save(entity)` (Cập nhật khi entity đã có id)
  + Delete: `deleteById(id)`, `delete(entity)` (Xóa)
- Định nghĩa các câu truy vấn thông minh theo cú pháp hàm (Derived Query Methods):
  + Spring Data JPA tự động dịch tên hàm thành câu lệnh SQL tương ứng mà lập trình viên không cần viết SQL.
  Ví dụ:
    * `findByEmail(String email)` -> Sinh ra SQL: `SELECT * FROM users WHERE email = ?`
    * `findByNameContainingIgnoreCase(String name)` -> Tìm kiếm gần đúng không phân biệt hoa thường.
    * `findByPriceBetween(Double minPrice, Double maxPrice)` -> Tìm sản phẩm trong khoảng giá.
- Hỗ trợ viết truy vấn phức tạp:
  + Sử dụng annotation `@Query` với JPQL (Java Persistence Query Language) hoặc Native SQL (SQL thuần).
  + Hỗ trợ các câu lệnh join nhiều bảng, tính toán thống kê (SUM, COUNT, AVG), lọc nâng cao.
- Hỗ trợ phân trang và sắp xếp dữ liệu (Pagination & Sorting):
  + Tích hợp sẵn `Pageable` và `Sort` để lấy dữ liệu trang (Page 1, 2, 3...) nhanh chóng mà không làm tràn bộ nhớ khi bảng có hàng ngàn dòng.
- Trừu tượng hóa hệ quản trị CSDL:
  + Code ở tầng Service hoàn toàn độc lập với hệ quản trị CSDL (MySQL, PostgreSQL, SQL Server, Oracle). Khi đổi database, chỉ cần đổi cấu hình, code Repository giữ nguyên.

3. VÍ DỤ CÁC REPOSITORY TRONG DỰ ÁN SHOP GIÀY THỂ THAO:
- ProductRepository:
  + `List<Product> findByBrandId(Long brandId);`
  + `Page<Product> findByCategoryName(String categoryName, Pageable pageable);`
  + `List<Product> findByNameContainingIgnoreCase(String keyword);`
  + `@Query("SELECT p FROM Product p WHERE p.price <= :maxPrice")`
- UserRepository:
  + `Optional<User> findByUsername(String username);`
  + `Optional<User> findByEmail(String email);`
  + `boolean existsByUsername(String username);`
  + `boolean existsByEmail(String email);`
- OrderRepository:
  + `List<Order> findByUserId(Long userId);`
  + `List<Order> findByStatus(String status);`

4. VỊ TRÍ TRONG MÔ HÌNH KIẾN TRÚC:
   Controller 
      ---> Service (Gọi Repository) 
         ---> Repository (Giao tiếp Hibernate / JPA) 
            ---> Database (MySQL / PostgreSQL / ...)
